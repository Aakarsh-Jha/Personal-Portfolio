2026 Cloud · Kubernetes · Performance

NGINX Ingress Load Balancing on Azure AKS

Engineered a reproducible cloud testbed deploying containerized microservices on a 2-node Azure Kubernetes Service (AKS) cluster utilizing the NGINX Ingress Controller. Evaluated Round Robin, Least Connections (EWMA), and IP Hashing under asymmetric loads up to 200 concurrent users via Locust—discovering dynamic EWMA reduced tail-latency (P99) by up to 55% (110–120ms vs 170ms) and established 99.99%+ availability during pod termination failovers.
